# 0.2.0

- Обои, звук, кадрирование и плейлист отдельно для каждого монитора.
- Автопауза для полноэкранных приложений, батареи, блокировки и сна; ручная пауза сохраняется.
- Избранное, четыре подборки настроений, очередь с интервалом, случайным порядком и расписанием через полночь.
- Превью кадрирования, горизонтальный и вертикальный фокус, заполнение или вписывание.
- Переключение сцен с проявлением видео поверх последнего кадра, если снимок доступен.
- Drag-and-drop, копирование новых импортов в постоянную библиотеку, тихое превью карточек.
- Камера, параллакс, свет и локальные деформации во всех 18 встроенных циклах.
- Установщик для текущего пользователя, обновление через GitHub с проверкой SHA-256, сборка релизов в Actions.
- Миграция старых настроек, отдельные журналы подложек, восстановление назначений при смене дисплеев.

Полноценной персонажной анимации нет; эффекты построены поверх исходных иллюстраций. Локальная аппаратная проверка выполнена на одном мониторе.
