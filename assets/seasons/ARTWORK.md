# Seasons artwork and animation

Six original scene plates were generated using the built-in OpenAI ImageGen tool.
Each production prompt is saved beside its image as `ID.prompt.txt`.
The cafe plate was cleaned of a generated signature in `1302-clean.png`; its
targeted edit prompt is saved in `1302-clean.prompt.txt`. The original is preserved.

These are layered animated illustrations, not full generative character videos.
Source plates are 1672 × 941 pixels. The renderer exports at 3840 × 2160 / 60 FPS;
it does not make the original illustrations native 4K. Leaves and snow have
independent trajectories and depth bands. Water, clouds, steam, rain and light
are animated with masked shaders. The exact periodic animation is 12 seconds.

The original seasonal cursor drawings are generated by `tools/make_season_styles.py`
and dedicated under CC0 1.0. Every pack contains 17 Windows roles at five sizes,
including 24-frame animated loading cursors. No third-party art or cursor packs
were used in this collection.

The six ordinary wallpapers, themes and cursor schemes are free. GitHub star
verification applies only to the existing three interactive Afterlight palettes.
