## VWP 0.5.2

Исправлено краткое появление обычных обоев Windows при повторе видео. VLC на мгновение убирает видеокадр на стыке петли; теперь под видеослоем постоянно находится постер текущей сцены. Поэтому фон не исчезает даже во время перезапуска видеопотока. Воспроизведение, пауза и выбор сцен работают как раньше.

Исправление проверено на рабочем столе Windows с шестисекундной встроенной сценой: до него обычные обои появлялись при каждом цикле, после него за 220 последовательных снимков через несколько циклов не появились ни разу. Настройки и импортированные файлы сохраняются при обновлении.
