# VWP 0.7.1 — восстановление города и запуск на встроенной графике

Исправлена ошибка, из-за которой окно Afterlight закрывалось с сообщением «Видеодвижок города остановился» при временной задержке рендера или перезапуске вспомогательного процесса WebView2.

- События GPU и служебных процессов не считаются фатальными. Единичное предупреждение о занятом рендере не закрывает город.
- При падении рендера или сбросе WebGL-контекста город пытается восстановиться в режиме «Экономия». Последняя позиция, район и пауза сохраняются; число попыток ограничено двумя.
- Режим «Авто» запускается с меньшим внутренним разрешением, тенями 1024 и без MSAA, затем повышает разрешение по результатам измерения кадров. Максимальное качество остаётся отдельным режимом.
- Подсказка установить WebView2 появляется только при отсутствии Runtime. Причины других сбоев записываются в `%LOCALAPPDATA%/VWP/city-runtime.log`.
- Заголовок, кнопка входа и подсказки города больше не накладываются друг на друга в небольшом окне и при увеличенном масштабе Windows.
- Сохранены все обои, темы и курсоры 0.7.0. Видео не перерендериваются: неизменённые мастеры берутся из официального архива 0.7.0 с проверкой закреплённой SHA-256. Приложение собирается заново из исходников.
- Все три интерактивных города по-прежнему требуют проверки звезды от собственного GitHub-аккаунта пользователя.

Для 3D нужен Microsoft Edge WebView2 Runtime. Скорость зависит от видеокарты; для слабого ПК рекомендуем «Экономию».
