# VWP 0.9.0 — Autumn & Winter

Six new living seasonal wallpapers with six matching themes and six native cursor
schemes. Autumn: Maple Afterglow, Rainy Chestnut, Copper Lake. Winter: Sapporo Blue,
Snowfall Onsen, Winter Vinyl.

Maple leaves turn and fall, snow drifts in depth, water ripples, rain falls outside
the cafe, steam curls over hot water and coffee, and warm lights gently shimmer.
Each scene has a seamless 12-second cycle, a 4K60 movie and a lightweight launcher
preview. Source illustrations are 1672 × 941; animation is exported at 4K.

The full catalog now contains 91 library records, 54 themes and 55 cursor schemes
(935 native CUR/ANI role files). All earlier wallpapers remain included. The three
interactive Afterlight palettes keep their GitHub star verification requirement.
The new seasonal collection is available to everyone.

For a weaker PC, use **Экономия** (720p15 playback proxy) or **Баланс** (1080p30).
Original 4K60 movies remain available in **Качество**. Themes provide matching
launcher/Windows colors, a still background and an optional native cursor scheme;
select the matching scene in the wallpaper library for animated playback.

Artwork prompts and generation/animation details are in `assets/seasons/ARTWORK.md`.
