# VWP — нативные видеообои

C# / .NET 8 / WPF / LibVLC. Светлый лаунчер в современном Apple-стиле: крупный баннер, карточки сцен, спокойная типографика и мягкие скругления.

## Запуск

Установите .NET 8 SDK, затем выполните `dotnet run --project VWP.csproj`.

Для автономной сборки: `powershell -ExecutionPolicy Bypass -File .\build.ps1`. Переносите всю папку `dist/VWP-v2` и запускайте `VWP.exe`. Python и .NET на целевом компьютере не нужны.

## Возможности

- Видео за значками рабочего стола, циклическое воспроизведение через VLC.
- Три оригинальные сцены в аниме-стилистике, импорт MP4/WebM/MKV/MOV/AVI.
- Выбор монитора, громкость, пауза, остановка, превью.
- Закрытие окна сворачивает лаунчер в трей; «Выход» в трее выключает обои и приложение.
- Круглые кнопки в стиле macOS: красная завершает приложение, жёлтая сворачивает в трей, зелёная переключает полноэкранный и компактный режимы. Esc возвращает компактный режим. Верхняя панель позволяет перетаскивать окно; края — менять размер.
- Автозапуск текущего пользователя с восстановлением последней сцены.
- Настройки: `%LOCALAPPDATA%/VWP/settings.json`. Импорт сохраняет путь, не копирует видео.

## Пресеты

Sakura Midnight, Neon Tokyo и Crimson Moon — оригинальные шестисекундные сцены на основе AI-иллюстраций с анимированными частицами. Персонаж и фон являются неподвижной иллюстрацией. Это не нарезки сериалов; собственные аниме-эдиты можно импортировать. Исходники и описание генерации находятся в assets.

Python используется только для необязательной генерации ассетов: `pip install Pillow imageio-ffmpeg`, затем `python tools/make_presets.py`.

## Ограничения первой версии

Windows 10/11 с Explorer. Один выбранный монитор. Нет Workshop, плейлистов, автоматической паузы в играх и установщика. WorkerW — недокументированный слой Explorer; совместимость со всеми сборками Windows не гарантируется. После смены мониторов или перезапуска Explorer примените обои снова. Превью использует системный MediaElement, который поддерживает меньше кодеков, чем VLC в обоях.

Автозапуск включайте из собранного VWP.exe; после переноса приложения переключите его заново. Права администратора не требуются. Токены и секреты не храните в репозитории.

## Проверка

`VWP.exe --verify` сохраняет рендеры компактного и полноэкранного лаунчера и result.json в подпапку verification рядом с приложением. Проверка кратковременно применяет каждый пресет, проверяет воспроизведение после завершения первого цикла, паузу, восстановление компактного размера и сворачивание в трей; после проверки завершает приложение. Приложение должно быть закрыто перед проверкой.
