# VWP — нативные видеообои

[Скачать релиз для Windows x64](https://github.com/domovoyproj/VWP/releases/latest). Распакуйте архив целиком и запустите VWP.exe из папки VWP.

C# / .NET 8 / WPF / LibVLC. Светлый лаунчер в современном Apple-стиле: крупный баннер, карточки сцен, спокойная типографика и мягкие скругления.

![Лаунчер VWP](docs/launcher.png)

## Запуск

Установите .NET 8 SDK, затем выполните `dotnet run --project VWP.csproj`.

Для автономной сборки: `powershell -ExecutionPolicy Bypass -File .\build.ps1`. Переносите всю папку `dist/VWP-v2` и запускайте `VWP.exe`. Python и .NET на целевом компьютере не нужны.

## Возможности

- Видео за значками рабочего стола, циклическое воспроизведение через VLC.
- 18 оригинальных сцен: аниме, города, природа, космос, фэнтези и абстракция; импорт MP4/WebM/MKV/MOV/AVI.
- Поиск по названию, категории и прокручиваемая сетка карточек.
- Выбор монитора, громкость, пауза, остановка, превью.
- Закрытие окна сворачивает лаунчер в трей; «Выход» в трее выключает обои и приложение.
- Круглые кнопки в стиле macOS: красная завершает приложение, жёлтая сворачивает в трей, зелёная переключает полноэкранный и компактный режимы. Esc возвращает компактный режим. Верхняя панель позволяет перетаскивать окно; края — менять размер.
- Автозапуск текущего пользователя с восстановлением последней сцены.
- Настройки: `%LOCALAPPDATA%/VWP/settings.json`. Импорт сохраняет путь, не копирует видео.
- При Alt+Tab/Peek под видео находится изображение выбранной сцены, чтобы Windows не показывала прежние обои. При остановке/выходе прежняя картинка возвращается. Изменение картинки самим пользователем сохраняется. Журнал восстановления подложки: `%LOCALAPPDATA%/VWP/desktop-backup.json`.
- Оригинальная иконка VWP встроена в EXE, окно и трей; исходник в assets/app.svg.

## Пресеты

Sakura Midnight, Neon Tokyo, Crimson Moon и ещё 15 сцен — оригинальные шестисекундные циклы на основе AI-иллюстраций. Дождь, снег, искры, пузырьки, светлячки и частицы анимированы; персонаж и фон являются неподвижной иллюстрацией. Это не нарезки сериалов; собственные аниме-эдиты можно импортировать. Каталог — assets/presets.json, исходники и промпты — assets/ARTWORK.md и assets/NEW_ARTWORK.md.

![Коллекция из 18 сцен](docs/collection.png)

Python используется только для необязательной генерации ассетов: `pip install Pillow imageio-ffmpeg`, затем `python tools/make_presets.py`.

Для упаковки сборки: `python tools/package_release.py --version 0.1.0`. Скрипт проверяет CRC архива и создаёт SHA-256. `python tools/verify_presets.py` полностью декодирует все 18 видео и проверяет изображения и размеры ICO. Лицензии поставляемых библиотек включены в папку licenses.

## Ограничения первой версии

Windows 10/11 с Explorer. Один выбранный монитор. Нет Workshop, плейлистов, автоматической паузы в играх и установщика. WorkerW — недокументированный слой Explorer; совместимость со всеми сборками Windows не гарантируется. После смены мониторов примените обои снова; замена слоя Explorer восстанавливается автоматически. Превью использует системный MediaElement, который поддерживает меньше кодеков, чем VLC в обоях.

Автозапуск включайте из собранного VWP.exe; после переноса приложения переключите его заново. Права администратора не требуются. Токены и секреты не храните в репозитории.

## Проверка

`VWP.exe --verify` сохраняет рендеры компактного и полноэкранного лаунчера и result.json в подпапку verification рядом с приложением. Проверка кратковременно применяет каждый пресет, проверяет воспроизведение после завершения первого цикла, паузу, восстановление компактного размера и сворачивание в трей; после проверки завершает приложение. Приложение должно быть закрыто перед проверкой.
